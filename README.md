# Assignment 5: Private vs Shared Amenities

[`assignment-5.ipynb`](assignment-5.ipynb) classifies Manhattan apartment descriptions and generates neighborhood and apartment-location maps. [`assignment-guide.md`](assignment-guide.md) records the definitions and workflow; [`index.html`](index.html) contains the submission webpage.

The notebook and saved CSV, GeoJSON and HTML exports use the private/shared amenities definition. Open `index.html` to view both maps and download the source StreetEasy CSV. The saved notebook records a completed run with no cell errors.
